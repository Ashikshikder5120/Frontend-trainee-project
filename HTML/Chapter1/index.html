Exploring the Foundations of HTML Elements

.1 Two Types of HTML Elements

An HTML element typically has three portions: an opening tag, the content, and a closing tag. Some elements without content don't need a closing tag.

.2 HTML Document Structure

The <html> element is the root, containing <head> (metadata) and <body> (visible elements).

.4 Character Encoding & .5 Element Attributes

Using charset="UTF-8" ensures all global characters display correctly, while the lang attribute sets the page's primary language.

.6 Favorite Icon & .7 Comments

Favicons improve site branding in browser tabs. Comments like <!-- comment --> are used to make the code more readable for developers.
