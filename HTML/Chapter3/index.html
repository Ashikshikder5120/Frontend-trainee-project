CHAPTER 3: HTML Styles

Text Formatting Elements and Inline Styling Concepts

.1 Formatting Elements

Based on Neo D. Truman's guide, we use specific tags for semantic emphasis:

  • .1.1 <b>: Bold text for visual weight.
  • .1.2 <i>: Italic text for emphasis.
  • .1.3 <u> / <ins>: Underlined text for highlights.
  • .1.4 <s> / <del>: Strikethrough for inaccurate data.
  • .1.5 <mark>: Highlighted text using background color.
  • .1.6 <sub> & <sup>: Subscript (H2O) and Superscript (E=mc2).
