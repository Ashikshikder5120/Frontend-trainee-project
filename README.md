# 🎓 Frontend Trainee Project

A comprehensive HTML, CSS & JavaScript learning dashboard built during my frontend trainee program — featuring a working authentication system, authorization-gated lessons, and a live progress-tracking dashboard.

## 🔗 Live Demo
https://ashikshikder5120.github.io/Frontend-trainee-project/

## ✨ Features
- 🔐 Client-side authentication (Sign up / Login) with hashed passwords
- 🔒 Authorization — lessons locked until login
- 📊 Modern dashboard with real-time progress tracking
- 📱 Fully responsive with mobile hamburger menu
- 🌙 Persistent dark mode
- 📬 Working contact form

## 🛠️ Tech Stack
HTML5, CSS3, JavaScript (Vanilla), Web Crypto API, LocalStorage
